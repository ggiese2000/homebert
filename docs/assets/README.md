# Artwork

## `homebert.png`

Das homeBert-Maskottchen wurde speziell für dieses Projekt erstellt. Es dient
als illustrative Darstellung der lokalen Verbindung zwischen Apple Home, BLE
und einem Receiver; es stellt keine Unterstützung oder Freigabe durch Apple
oder Nubert dar.

## `homekit-uebersicht.png` und `homekit-steuerung.png`

Diese Screenshots stammen vom Gerät des Maintainers. Sichtbare Namen wurden
vor der Veröffentlichung bewusst geschwärzt. Sie dokumentieren nur die
Darstellung von homeBert in Apple Home und implizieren keine Unterstützung,
Partnerschaft oder Freigabe durch Apple oder Nubert.

Die Bilder werden ausschließlich in der Projekt-README verwendet.

## `homeBert-Schnellübersicht.png`

Diese vom Projektmaintainer bereitgestellte Grafik dient als physische
Kurzübersicht für ATOM Lite, Fronttaster und seitlichen Reset-Taster. Sie wird
in der README verwendet. Ihr Hinweis auf einen „konfigurierten normalen
LED-Modus“ bezieht sich ausschließlich auf Anpassungen des Firmware-Quellcodes
mit anschließendem Neubau; eine Auswahl eines LED-Modus in der Einrichtung
gibt es nicht. Die Formulierung ist daher eine redaktionelle Ambiguität, keine
abweichende Firmwarefunktion. Für alle Bedien- und LED-Details bleibt
[LED und Taster](../LED_AND_BUTTON.md) maßgeblich.

Die Grafik wurde auf Veranlassung des Projektmaintainers mit OpenAI ChatGPT
für homeBert neu erstellt. Als gestalterische Referenz diente eine vom
Maintainer bereitgestellte Vorlage. Der Maintainer bestätigt, zur Verwendung
und Veröffentlichung der Grafik im öffentlichen homeBert-Repository berechtigt
zu sein. Die Grafik ist keine offizielle Dokumentation des
Hardwareherstellers.
